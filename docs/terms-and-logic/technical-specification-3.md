# Техническое задание #3: Калькулятор чаевых с проверкой ввода

#### Цель проекта

Разработать консольное Go-приложение для расчёта распределения общей суммы счёта с учётом чаевых между участниками обеда с интерактивным вводом данных и **проверкой корректности**.

### Функциональные требования
### 1. Ввод данных с валидацией

#### Сумма счёта (`billAmount`)
- **Тип данных:** `float64`
- **Приглашение:** "Введите сумму счёта: "
- **Способ ввода:** `fmt.Scanln()`(или любой из известных) со `strconv.ParseFloat()`
- **Проверка:** Значение должно быть **положительным** числом (> 0)
- **Ошибка:** "Ошибка: введено некорректное значение. Сумма счёта должна быть положительным числом."

#### Процент чаевых (`tipPercentage`)
- **Тип данных:** `float64`
- **Приглашение:** "Введите процент чаевых: "
- **Способ ввода:** `fmt.Scanln()` со `strconv.ParseFloat()`
- **Проверка:** Значение должно быть **неотрицательным** числом (≥ 0)
- **Ошибка:** "Ошибка: введено некорректное значение. Процент чаевых должен быть неотрицательным числом."

#### Количество участников (`numberOfPeople`)
- **Тип данных:** `int`
- **Приглашение:** "Введите количество участников: "
- **Способ ввода:** `fmt.Scanln()` со `strconv.Atoi()` или `strconv.ParseInt()`
- **Проверка:** Значение должно быть **положительным** целым числом (> 0)
- **Ошибка:** "Ошибка: введено некорректное значение. Количество участников должно быть положительным целым числом."

### 2. Обработка некорректного ввода

- При вводе **нечисловых** значений программа выводит сообщение об ошибке
- При вводе **некорректных** диапазонов (отрицательные, нулевые) программа выводит сообщение об ошибке
- **При любой ошибке** программа завершает выполнение
- Сообщение об ошибке выводится перед завершением

### 3. Расчёты

**Сумма чаевых (`tipAmount`):**
```
tipAmount = billAmount × tipPercentage ÷ 100
```

**Общая сумма (`totalAmount`):**
```
totalAmount = billAmount + tipAmount
```

**Сумма на одного человека (`perPersonAmount`):**
```
perPersonAmount = totalAmount ÷ float64(numberOfPeople)
```

### 4. Вывод результатов

Форматированный вывод с `fmt.Printf()`:
- `%.2f` — два знака после запятой
- `%d` — целые числа
- `%%` — символ процента

## 📋 Примеры работы

### Пример 1: Некорректная сумма счёта

```
=== Калькулятор чаевых ===

Введите сумму счёта: abc
Ошибка: введено некорректное значение. 
Сумма счёта должна быть положительным числом.
```

### Пример 2: Отрицательный процент чаевых

```
=== Калькулятор чаевых ===

Введите сумму счёта: 1000
Введите процент чаевых: -10
Ошибка: введено некорректное значение. 
Процент чаевых должен быть неотрицательным числом.
```

### Пример 3: Нулевое количество участников

```
=== Калькулятор чаевых ===

Введите сумму счёта: 1000
Введите процент чаевых: 10
Введите количество участников: 0
Ошибка: введено некорректное значение. 
Количество участников должно быть положительным целым числом.
```

### Пример 4: Успешный расчёт

```
=== Калькулятор чаевых ===

Введите сумму счёта: 1500
Введите процент чаевых: 15
Введите количество участников: 3

--- Результаты ---
Сумма счёта: 1500.00
Процент чаевых: 15.0%
Сумма чаевых: 225.00
Общий счёт: 1725.00
Количество участников: 3
С каждого: 575.00
```
