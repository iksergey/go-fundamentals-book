# Условная конструкция if-else: полная форма

## Краткое описание

**Полная форма условия** включает блок **else**, который выполняется, когда условие **не выполнено** (возвращает false). В отличие от сокращённой формы (только if), полная форма позволяет программе реагировать **двумя разными способами** в зависимости от результата проверки условия.

***

## Синтаксис if-else

### Структура

    if условие {
        // Блок 1: выполняется если условие == true
    } else {
        // Блок 2: выполняется если условие == false
    }

### Ключевые особенности

1. **Ключевое слово else** идёт **сразу после закрывающей } блока if**
2. **Только один блок** выполняется (либо if, либо else)
3. В каждом блоке может быть **сколько угодно операторов**
4. Все операторы должны быть заключены в **фигурные скобки { }**

***

## Логика работы if-else

### Алгоритм выполнения

1. **Проверяется условие**
2. **Если условие = true** → выполняется блок if, блок else **пропускается**
3. **Если условие = false** → блок if **пропускается**, выполняется блок else
4. После выполнения одного из блоков программа **продолжает** дальше

### Важно

- **Взаимоисключающие блоки:** выполняется **ровно один** из двух блоков
- **Гарантия выполнения:** один из блоков **всегда** выполнится
- **Альтернативные сценарии:** if-else позволяет программе выбирать между двумя путями

***

## Пример 1: Проверка температуры

### Задача

Программа должна сообщать:
- **"Тепло"** — если температура больше 20 градусов
- **"Холодно, надевайте куртку"** — если температура 20 градусов или меньше

### Код

    temperature := 10
    fmt.Printf("temperature = %d\n", temperature)

    if temperature > 20 {
        fmt.Println("Тепло, надевайте лёгкую одежду")
        fmt.Println("Тепло, надевайте лёгкую одежду")
        fmt.Println("Тепло, надевайте лёгкую одежду")
        fmt.Println("Тепло, надевайте лёгкую одежду")
        fmt.Println("Тепло, надевайте лёгкую одежду")
    } else {
        fmt.Println("Холодно, надевайте куртку")
        fmt.Println("Холодно, надевайте куртку")
        fmt.Println("Холодно, надевайте куртку")
        fmt.Println("Холодно, надевайте куртку")
        fmt.Println("Холодно, надевайте куртку")
        fmt.Println("Холодно, надевайте куртку")
    }

### Анализ работы

**Вариант 1: temperature = 10**
- Проверка: 10 > 20 → **false**
- Блок if **пропускается**
- Выполняется блок **else**
- Вывод: "Холодно, надевайте куртку" (6 раз)

**Вариант 2: temperature = 20**
- Проверка: 20 > 20 → **false**
- Блок if **пропускается**
- Выполняется блок **else**
- Вывод: "Холодно, надевайте куртку"

**Вариант 3: temperature = 21**
- Проверка: 21 > 20 → **true**
- Выполняется блок **if**
- Блок else **пропускается**
- Вывод: "Тепло, надевайте лёгкую одежду" (5 раз)

### Модификация условия

Если нужно, чтобы 20 градусов считались тёплыми:

    if temperature >= 20 {  // >= вместо >
        fmt.Println("Тепло")
    } else {
        fmt.Println("Холодно")
    }

## Пример 2: Банкомат (проверка баланса)

### Задача

Пользователь хочет снять деньги с карты. Программа должна:
1. **Проверить баланс**
2. **Если денег достаточно:** выдать деньги и показать остаток
3. **Если денег недостаточно:** сообщить об ошибке

### Код

    balance := 1250.0
    withdrawAmount := 1000.0

    fmt.Printf("balance = %.2f\n", balance)
    fmt.Printf("withdrawAmount = %.2f\n", withdrawAmount)

    if balance >= withdrawAmount {
        fmt.Println("Достаточно средств, вывод разрешен")
        finalBalance := balance - withdrawAmount
        fmt.Printf("Оставшийся баланс: %.2f\n", finalBalance)
    } else {
        fmt.Println("Недостаточно средств")
        fmt.Printf("Не хватает: %.2f\n", withdrawAmount-balance)
    }

### Анализ работы

**Сценарий 1: balance = 500, withdrawAmount = 1000**
- Проверка: 500 >= 1000 → **false**
- Блок if **пропускается**
- Выполняется блок **else**
- Вывод:
  - "Недостаточно средств"
  - "Не хватает: 500.00"

**Сценарий 2: balance = 1250, withdrawAmount = 1000**
- Проверка: 1250 >= 1000 → **true**
- Выполняется блок **if**
- Блок else **пропускается**
- Вычисления: 1250 - 1000 = 250
- Вывод:
  - "Достаточно средств, вывод разрешен"
  - "Оставшийся баланс: 250.00"

### Бизнес-логика

Этот пример демонстрирует типичную валидацию:
1. **Проверка перед действием:** сначала проверяем возможность операции
2. **Два исхода:** либо операция выполняется, либо выводится ошибка
3. **Безопасность:** деньги списываются только если баланс достаточен

***

## Множественные операции в блоках

### В блоке if может быть сколько угодно операторов

    if balance >= withdrawAmount {
        // Операция 1
        fmt.Println("Достаточно средств, вывод разрешен")
        
        // Операция 2: вычисление
        finalBalance := balance - withdrawAmount
        
        // Операция 3: вывод результата
        fmt.Printf("Оставшийся баланс: %.2f\n", finalBalance)
        
        // Операция 4: дополнительная информация
        fmt.Println("Заберите деньги в купюроприемнике")
    }

### В блоке else тоже может быть много операторов

    } else {
        // Операция 1
        fmt.Println("Недостаточно средств")
        
        // Операция 2: показываем нехватку
        shortage := withdrawAmount - balance
        fmt.Printf("Не хватает: %.2f\n", shortage)
        
        // Операция 3: показываем текущий баланс
        fmt.Printf("Ваш баланс: %.2f\n", balance)
        
        // Операция 4: совет
        fmt.Println("Уменьшите сумму снятия")
    }

## Тестирование кода мысленно

### Методика

**Перед запуском программы:**
1. Запишите значения переменных
2. Подставьте их в условие
3. Определите результат (true или false)
4. Предскажите, какой блок выполнится
5. Предскажите вывод на экран

### Пример тестирования

**Дано:**

    temperature := 20
    if temperature > 20 { ... } else { ... }

**Рассуждение:**
- temperature = 20
- Условие: 20 > 20
- Вопрос: это истина или ложь?
- Ответ: **ложь** (20 не больше 20)
- Вывод: выполнится блок **else**
- Ожидаем: "Холодно, надевайте куртку"

**Запуск программы → результат совпадает!**

***

## Форматирование вывода

### Спецификаторы формата

    balance := 1250.5
    withdrawAmount := 1000.0

    // %.2f — вещественное число с 2 знаками после запятой
    fmt.Printf("balance = %.2f\n", balance)           // 1250.50
    fmt.Printf("withdrawAmount = %.2f\n", withdrawAmount)  // 1000.00

    finalBalance := balance - withdrawAmount
    fmt.Printf("Оставшийся баланс: %.2f\n", finalBalance)  // 250.50

### Почему %.2f?

- **%f** — вещественное число (float)
- **.2** — два знака после запятой
- Удобно для денежных операций

***

## Сравнение форм условий

### Сокращённая форма (только if)

    if age >= 18 {
        fmt.Println("Доступ разрешен")
    }
    // Если age < 18, ничего не произойдёт

**Использование:** когда нужно что-то сделать только при выполнении условия.

### Полная форма (if-else)

    if age >= 18 {
        fmt.Println("Доступ разрешен")
    } else {
        fmt.Println("Доступ запрещен")
    }
    // Один из блоков ОБЯЗАТЕЛЬНО выполнится

**Использование:** когда нужно реагировать на **оба** исхода проверки.

***

## Практические примеры

    number := 7

    } else {
        fmt.Println("Число нечётное")

    username := "admin"

    }

## Ключевые моменты

1. **Полная форма** — if + else
2. **Два блока:** один для true, другой для false
3. **Взаимоисключающие:** выполняется **только один** блок
4. **Гарантия:** **всегда** выполнится один из блоков
5. **Множественные операции:** в каждом блоке может быть много кода
6. **else идёт сразу после }** блока if (на той же строке)
7. **Фигурные скобки обязательны** для обоих блоков
8. **Тестирование:** проверяйте код мысленно перед запуском
9. **Форматирование:** используйте Printf и спецификаторы для красивого вывода
10. **Валидация:** проверяйте условия перед выполнением операций

***

## Синтаксические правила

### ✅ Правильно

    if condition {
        // code
    } else {
        // code
    }

### ❌ Неправильно

    // Ошибка: else на новой строке
    if condition {
        // code
    }
    else {
        // code
    }

### ✅ Правильно: с переносами внутри блоков

    if balance >= withdrawAmount {
        fmt.Println("Достаточно средств")
        finalBalance := balance - withdrawAmount
        fmt.Printf("Остаток: %.2f\n", finalBalance)
    } else {
        fmt.Println("Недостаточно средств")
        fmt.Printf("Не хватает: %.2f\n", withdrawAmount-balance)
    }

## Что запомнить

- **if-else** — полная форма условия
- **Два пути:** один для истины, другой для лжи
- **Только один** блок выполнится
- **else** идёт сразу после } блока if
- Можно писать **много операций** в каждом блоке
- **Тестируйте** код мысленно
- Используйте для **альтернативных сценариев**
- **Валидация** — классическое применение if-else
- **Форматирование** — %.2f для денег

***

**Итог:** Полная форма if-else позволяет программе выбирать между двумя альтернативными сценариями в зависимости от результата проверки условия. Это делает код более предсказуемым и позволяет обрабатывать все возможные исходы.
