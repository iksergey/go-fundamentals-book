# Условная конструкция `if`: базовый синтаксис

## Краткое описание

Условные конструкции — **фундамент логики** любой программы. Они позволяют коду принимать разные действия на основе заданных условий, превращая простую последовательность команд (выполняемых сверху вниз, слева направо) в адаптивную систему, реагирующую на разные ситуации. Без условных конструкций программа могла бы выполнять только **линейные операции**.

## Как работает условие

### Принцип работы

Программа по умолчанию выполняется **последовательно**: сверху вниз, слева направо. Условная конструкция создаёт **развилку**:

```
┌─────────────────┐
│   Команды       │
└────────┬────────┘
         │
    ┌────▼────┐
    │ Условие │
    │ истина? │
    └──┬───┬──┘
  Да   │   │  Нет
   ┌───▼────┐ │
   │Действие│ │
   └───┬────┘ │
       └──┬───┘
          │
    ┌─────▼──────┐
    │ Продолжение│
    └────────────┘
```

**Правило:** условие **всегда** должно возвращать **`bool`** (истину или ложь).

### Логика выполнения

1. **Если условие = `true`** → выполняется блок кода внутри `{}`
2. **Если условие = `false`** → блок кода **пропускается**
3. Программа продолжает выполнение **после** блока `if`

## Базовый синтаксис `if` в Go

### Структура

```go
if условие {
    // Код выполняется только если условие == true
}
```

### Ключевые особенности синтаксиса Go

**⚠️ КРИТИЧЕСКИ ВАЖНО:**

1. **Условие БЕЗ круглых скобок** (в отличие от C, Java, C#)
2. **Фигурные скобки `{}` ОБЯЗАТЕЛЬНЫ** (даже для одной строки кода)
3. Условие должно возвращать **`bool`**

```go
// ✅ ПРАВИЛЬНО (Go-стиль)
if age >= 18 {
    fmt.Println("Совершеннолетний")
}

// ❌ ОШИБКА: круглые скобки не нужны
if (age >= 18) {
    fmt.Println("Совершеннолетний")
}

// ❌ ОШИБКА: фигурные скобки обязательны
if age >= 18
    fmt.Println("Совершеннолетний")
```

## Примеры использования

### Пример 1: Проверка возраста

```go
age := 25
fmt.Printf("age = %d\n", age)

if age >= 18 {
    fmt.Println("Возраст >= 18")
    fmt.Println("Доступ разрешен")
}

// Вывод:
// age = 25
// Возраст >= 18
// Доступ разрешен
```

**Что происходит:**
1. `age = 25`
2. Проверка: `25 >= 18` → `true`
3. Выполняются ОБА `fmt.Println` внутри блока
4. Программа продолжается

### Пример 2: Условие не выполнено

```go
age := 15
fmt.Printf("age = %d\n", age)

if age >= 18 {
    fmt.Println("Возраст >= 18")
    fmt.Println("Доступ разрешен")
}

fmt.Println("Программа продолжается")

// Вывод:
// age = 15
// Программа продолжается
```

**Что происходит:**
1. `age = 15`
2. Проверка: `15 >= 18` → `false`
3. Блок кода **пропускается** (ничего не печатается)
4. Выполняется код **после** `if`

### Пример 3: Проверка баллов экзамена

```go
score := 55
fmt.Printf("score = %d\n", score)

if score >= 50 {
    fmt.Println("Экзамен сдан")
}

fmt.Println("Эта строка выполнится в любом случае")

// Вывод:
// score = 55
// Экзамен сдан
// Эта строка выполнится в любом случае
```

**Если `score = 45`:**

```go
score := 45

if score >= 50 {
    fmt.Println("Экзамен сдан")  // НЕ выполнится
}

fmt.Println("Эта строка выполнится в любом случае")

// Вывод:
// Эта строка выполнится в любом случае
```

### Пример 4: Сложные условия с логическими операторами

```go
name := "Alice"
isVerified := true

fmt.Printf("name = \"%s\", isVerified = %t\n", name, isVerified)

if isVerified && name != "" {
    fmt.Println("Пользователь верифицирован и имя не пусто")
}

// Вывод:
// name = "Alice", isVerified = true
// Пользователь верифицирован и имя не пусто
```

**Разбор условия:**
- `isVerified` → `true`
- `name != ""` → `"Alice" != ""` → `true`
- `true && true` → **`true`**
- Блок выполняется ✅

## Типы условий в `if`

### 1. Операции сравнения

```go
if age >= 18 { }      // Больше или равно
if score > 50 { }     // Больше
if temp < 0 { }       // Меньше
if count == 10 { }    // Равно
if status != 200 { }  // Не равно
```

### 2. Логические переменные

```go
isActive := true

if isActive {
    fmt.Println("Активен")
}

// НЕ пишите избыточно:
// if isActive == true { }  ❌
```

### 3. Комбинации с логическими операторами

```go
// AND (&&)
if age >= 18 && hasLicense {
    fmt.Println("Может водить")
}

// OR (||)
if day == "Saturday" || day == "Sunday" {
    fmt.Println("Выходной")
}

// NOT (!)
if !isBlocked {
    fmt.Println("Не заблокирован")
}

// Комбинация
if (age >= 18 && age <= 65) && isVerified {
    fmt.Println("Допущен к работе")
}
```

## Блок-схема условной конструкции

```
        Начало
           │
           ▼
    ┌──────────────┐
    │   age = 15   │
    └──────┬───────┘
           │
           ▼
    ╔══════════════╗
    ║ age >= 18?   ║
    ╚══════╦════╦══╝
      true │    │ false
           │    │
    ┌──────▼──┐ │
    │ Действие│ │
    │ print   │ │
    └──────┬──┘ │
           └─┬──┘
             │
             ▼
      ┌─────────────┐
      │ Продолжение │
      └─────────────┘
```

## Множественные операции в блоке

Внутри `{}` может быть **сколько угодно** операций:

```go
if score >= 90 {
    fmt.Println("Отлично!")
    grade := "A"
    bonus := 100
    fmt.Printf("Оценка: %s\n", grade)
    fmt.Printf("Бонус: %d\n", bonus)
}
```

**Все операции** выполнятся только если `score >= 90`.

## Ключевые моменты

1. **Условие возвращает `bool`**
   - Операции сравнения: `>=`, `>`, `<`, `<=`, `==`, `!=`
   - Логические операции: `&&`, `||`, `!`
   - Логические переменные: `isActive`

2. **Синтаксис Go**
   - БЕЗ круглых скобок вокруг условия
   - Фигурные скобки `{}` ОБЯЗАТЕЛЬНЫ
   - Открывающая `{` на той же строке, что и `if`

3. **Логика выполнения**
   - `true` → блок выполняется
   - `false` → блок пропускается
   - Код после `if` выполняется **всегда**

4. **Сложные условия**
   - Комбинируйте с `&&`, `||`, `!`
   - Используйте скобки для ясности

5. **Читаемость**
   - Можно писать несколько строк в блоке
   - Код после `if` выполнится в любом случае

## Практические примеры

### Проверка диапазона

```go
temperature := 22

if temperature >= 18 && temperature <= 25 {
    fmt.Println("Комфортная температура")
}
```

### Проверка статуса

```go
status := 200

if status == 200 || status == 201 {
    fmt.Println("Запрос успешен")
}
```

### Валидация данных

```go
username := "admin"
password := "12345"

if username != "" && password != "" {
    fmt.Println("Данные введены")
}
```

### Проверка авторизации

```go
isLoggedIn := true
isAdmin := false

if isLoggedIn && !isAdmin {
    fmt.Println("Обычный пользователь")
}
```

## Что запомнить

- **Условие = `bool`** (истина или ложь)
- **БЕЗ `()`** вокруг условия
- **С `{}`** обязательно
- **`true`** → выполняется
- **`false`** → пропускается
- Код **после** `if` выполняется **всегда**
- Можно использовать **операции сравнения** и **логические операторы**
- Открывающая `{` на **той же строке**, что и `if`

## Типичная ошибка новичков

```go
// ❌ ОШИБКА: фигурная скобка на новой строке
if age >= 18
{
    fmt.Println("Нет")
}

// ✅ ПРАВИЛЬНО
if age >= 18 {
    fmt.Println("Да")
}
```

В Go **обязательно** ставить `{` на той же строке, что и `if`!

***

**Итог:** Базовый `if` — это проверка условия (`bool`) и выполнение блока кода `{}` только если условие истинно. Синтаксис Go прост: `if условие { действия }`, без круглых скобок, но с обязательными фигурными.
