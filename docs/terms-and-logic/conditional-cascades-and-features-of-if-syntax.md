# Каскады условий и особенности синтаксиса if

## Краткое описание

**Каскад условий** (else if) — конструкция для проверки **множественных альтернативных условий** последовательно. Если первое условие не выполнено, проверяется второе, затем третье и так далее. Выполняется **только первый** блок, условие которого истинно. Go имеет особенности синтаксиса: **фигурные скобки обязательны**, **круглые скобки вокруг условия запрещены**, переменные имеют **область видимости** внутри блоков.

***

## Конструкция else if

### Синтаксис

    if условие1 {
        // Блок 1: выполняется если условие1 == true
    } else if условие2 {
        // Блок 2: выполняется если условие1 == false И условие2 == true
    } else if условие3 {
        // Блок 3: выполняется если условие1 == false И условие2 == false И условие3 == true
    } else {
        // Блок по умолчанию: выполняется если ВСЕ условия == false
    }

### Логика работы

1. **Последовательная проверка:** условия проверяются **сверху вниз**
2. **Первое совпадение:** выполняется **первый** блок, где условие true
3. **Остальные пропускаются:** после выполнения одного блока остальные **не проверяются**
4. **Блок else:** выполняется если **все** условия false (опционален)

***

## Пример 1: Оценка за тест

### Задача

Выставить оценку на основе баллов (максимум 100):
- **90+** → Отлично
- **80-89** → Хорошо
- **70-79** → Удовлетворительно
- **60-69** → Минимально
- **Меньше 60** → Неудовлетворительно

### Код

    grade := 75
    fmt.Printf("grade = %d\n", grade)

    if grade >= 90 {
        fmt.Println("Оценка: отлично")
    } else if grade >= 80 {
        fmt.Println("Оценка: хорошо")
    } else if grade >= 70 {
        fmt.Println("Оценка: удовлетворительно")
    } else if grade >= 60 {
        fmt.Println("Оценка: минимально")
    } else {
        fmt.Println("Оценка: неудовлетворительно")
    }

### Пошаговое выполнение (grade = 75)

**Шаг 1:** Проверяем 75 >= 90 → **false**, переходим к else if

**Шаг 2:** Проверяем 75 >= 80 → **false**, переходим к следующему else if

**Шаг 3:** Проверяем 75 >= 70 → **true** ✅

**Результат:** Выполняется блок "Оценка: удовлетворительно"

**Остальные блоки не проверяются!**

### Вывод

    grade = 75
    Оценка: удовлетворительно

## Пример 2: Размер одежды по весу

### Код

    weight := 62
    fmt.Printf("weight = %d кг\n", weight)

    if weight < 50 {
        fmt.Println("Размер: XS (очень маленький)")
    } else if weight < 60 {
        fmt.Println("Размер: S (маленький)")
    } else if weight < 75 {
        fmt.Println("Размер: M (средний)")
    } else if weight < 90 {
        fmt.Println("Размер: L (большой)")
    } else if weight < 110 {
        fmt.Println("Размер: XL (очень большой)")
    } else {
        fmt.Println("Размер: XXL (экстра большой)")
    }

### Мысленное тестирование (weight = 62)

**Проверяем 62 < 50?** Нет → следующее

**Проверяем 62 < 60?** Нет → следующее

**Проверяем 62 < 75?** **Да!** ✅

**Ожидаем:** Размер: M (средний)

**Запускаем → результат совпадает!**

### Граничные случаи

**Вопрос:** Что если weight = 75?

**Ответ:** 
- 75 < 50? Нет
- 75 < 60? Нет
- 75 < 75? **Нет** (75 не меньше 75)
- 75 < 90? **Да** → Размер L

**Вывод:** Граничное значение попадёт в **следующий** диапазон.

***

## Методика тестирования каскадов

### Алгоритм

1. **Запишите значение** переменной
2. **Проверьте первое условие** → если true, результат найден
3. **Если false** → переходите к следующему условию
4. **Повторяйте** до первого true
5. **Предскажите результат** перед запуском
6. **Запустите и сравните** с ожиданием

### Пример проверки

    grade := 62

**Мысленный путь:**
- 62 >= 90? Нет → else if
- 62 >= 80? Нет → else if
- 62 >= 70? Нет → else if
- 62 >= 60? **Да** ✅ → "Оценка: минимально"

## Фигурные скобки ОБЯЗАТЕЛЬНЫ

### Правило Go

В Go фигурные скобки { } **всегда обязательны**, даже для одной строки кода.

### ✅ Правильно

    x := 10

    if x > 5 {
        fmt.Println("x > 5")
    }

    // Даже для одной строки
    if x < 20 {
        fmt.Println("x < 20")
    }

### ❌ Неправильно (не скомпилируется)

    // ОШИБКА: нет фигурных скобок
    if x > 5
        fmt.Println("x > 5")

    // ОШИБКА: однострочный без скобок
    if x > 5 fmt.Println("x > 5")

### Почему так?

**В других языках:**
- **C#, Java, JavaScript:** скобки опциональны для одной строки
- **Python:** использует отступы вместо скобок

**В Go:** разработчики решили сделать синтаксис **единообразным** — скобки обязательны **всегда**.

***

## Круглые скобки вокруг условия НЕ нужны

### Правило Go

Условие в if **НЕ заключается** в круглые скобки (в отличие от C, Java, C#).

### Сравнение с другими языками

**Java / C# / JavaScript:**

    if (num > 10) {
        // код
    }

**Go:**

    if num > 10 {
        // код
    }

### ✅ Правильно в Go

    num := 15

    if num > 10 {
        fmt.Println("num > 10")
    }

### ❌ Неправильно (синтаксическая ошибка)

    // ОШИБКА: круглые скобки вокруг условия
    if (num > 10) {
        fmt.Println("num > 10")
    }

### Автоматическое форматирование

**VS Code с линтером:**
- Если написать (num > 10), при сохранении линтер **автоматически удалит** скобки
- Если линтер не настроен → **ошибка компиляции**

***

## Круглые скобки ВНУТРИ условия

### Когда можно использовать

Круглые скобки **разрешены внутри выражения** для задания приоритета операций.

### ✅ Правильное использование

    a := 5
    b := 10

    // Скобки внутри выражения (для приоритета)
    if (a + b) > 10 {
        fmt.Println("(a + b) > 10")
    }

    // Более сложный пример
    if (a + b) * 2 > 20 {
        fmt.Println("Сумма удвоенная больше 20")
    }

### Приоритет операций

**Без скобок:**

    if 2 * a + b > 10 {
        // 2 * a выполняется первым (приоритет умножения)
        // Затем + b
        // Затем сравнение
    }

**Со скобками:**

    if 2 * (a + b) > 10 {
        // Сначала (a + b) — скобки
        // Затем * 2
        // Затем сравнение
    }

### Важно

Круглые скобки — это **часть выражения**, а не обрамление условия!

## Область видимости переменных в блоках

### Правило

Переменные, объявленные **внутри блока** { }, видны **только в этом блоке**.

### Пример 1: Переменная внутри if

    if true {
        insideIfVar := 50
        fmt.Printf("insideIfVar = %d\n", insideIfVar)  // ✅ Работает
    }

    // ❌ ОШИБКА: undefined: insideIfVar
    // fmt.Println(insideIfVar)

**Область видимости:** insideIfVar существует только внутри блока if.

### Пример 2: Разные переменные в if и else

    temperature := 25

    if temperature > 20 {
        message := "Тепло"
        fmt.Printf("message = \"%s\"\n", message)  // ✅ Работает
    } else {
        message := "Холодно"
        fmt.Printf("message = \"%s\"\n", message)  // ✅ Работает
    }

    // ❌ ОШИБКА: undefined: message
    // fmt.Println(message)

**Важно:** Это **две разные переменные** с одинаковым именем, но в разных блоках!

### Пример 3: Переменная вне блока

    var outsideVar int = 100

    if true {
        fmt.Println(outsideVar)  // ✅ Видна внутри
    }

    fmt.Println(outsideVar)  // ✅ Видна снаружи

**Область видимости:** переменная, объявленная **вне блока**, видна **везде ниже**.

***

## Правильный способ: объявление снаружи

### Проблема

Нужно использовать переменную **после** блока if/else.

### ❌ Неправильно

    if temperature > 20 {
        status := "Тепло"
    } else {
        status := "Холодно"
    }

    // ОШИБКА: status не видна здесь
    fmt.Println(status)

### ✅ Правильно

    var status string  // Объявляем ВНЕ блока
    temperature := 15

    if temperature > 20 {
        status = "Тепло"  // Присваиваем (без :=)
    } else {
        status = "Холодно"  // Присваиваем (без :=)
    }

    fmt.Printf("status = \"%s\"\n", status)  // ✅ Видна здесь

### Ключевое отличие

- **:=** — объявление + присваивание (создаёт новую переменную)
- **=** — присваивание существующей переменной

***

## Визуализация области видимости

### Схема

    // Глобальная область
    var global int = 100
    
    if условие {
        // Область блока if
        var ifVar int = 50
        fmt.Println(global)  // ✅ Видна
        fmt.Println(ifVar)   // ✅ Видна
    } else {
        // Область блока else
        var elseVar int = 30
        fmt.Println(global)   // ✅ Видна
        fmt.Println(elseVar)  // ✅ Видна
        // fmt.Println(ifVar) // ❌ НЕ видна
    }
    
    // Снова глобальная область
    fmt.Println(global)   // ✅ Видна
    // fmt.Println(ifVar) // ❌ НЕ видна
    // fmt.Println(elseVar) // ❌ НЕ видна

## Практические примеры

## Ключевые моменты

1. **else if** — проверка множественных условий
2. **Последовательная проверка** — сверху вниз
3. **Первое совпадение** — выполняется только один блок
4. **Фигурные скобки { }** — **ОБЯЗАТЕЛЬНЫ всегда**
5. **Круглые скобки ( )** — **ЗАПРЕЩЕНЫ вокруг условия**
6. **Круглые скобки внутри** — разрешены для приоритета операций
7. **Область видимости** — переменные живут только в своём блоке
8. **Объявление снаружи** — если нужна переменная после блока
9. **:= vs =** — := создаёт новую, = присваивает существующей
10. **Мысленное тестирование** — проверяйте логику до запуска

***

## Best Practices

### 1. Не переусердствуйте с каскадами

    // ✅ Нормально: 4-5 условий
    if grade >= 90 { }
    else if grade >= 80 { }
    else if grade >= 70 { }
    else if grade >= 60 { }
    else { }

    // ❌ Слишком много (10+ условий)
    // Используйте switch (рассмотрим позже)

### 2. Упорядочивайте условия логично

    // ✅ От большего к меньшему
    if grade >= 90 { }
    else if grade >= 80 { }
    else if grade >= 70 { }

    // ❌ Хаотично
    if grade >= 70 { }
    else if grade >= 90 { }
    else if grade >= 80 { }

### 3. Проверяйте граничные значения

    weight := 75  // Что произойдёт?
    
    if weight < 75 {  // 75 < 75? Нет
        // Не выполнится
    }

### 4. Используйте явные переменные для сложных условий

    // ✅ Читаемо
    var category string
    if age < 18 {
        category = "Несовершеннолетний"
    } else {
        category = "Взрослый"
    }

### 5. Комментируйте неочевидные условия

    // Скидка 20% для VIP-клиентов с покупкой от 5000
    if isVIP && amount >= 5000 {
        discount = 0.20
    }

***

## Что запомнить

- **else if** — множественные альтернативы
- **Каскад** — проверка по порядку до первого true
- **{ } обязательны** — всегда, даже для одной строки
- **( ) запрещены** — вокруг условия
- **( ) разрешены** — внутри выражения для приоритета
- **Область видимости** — переменная живёт в своём блоке
- **Объявляйте снаружи** — если нужна после блока
- **Тестируйте мысленно** — проверяйте логику до запуска
- **Граничные случаи** — всегда проверяйте равенство

***

**Итог:** Каскады условий (else if) позволяют обрабатывать множественные альтернативные сценарии последовательно. Go требует обязательного использования фигурных скобок и запрещает круглые скобки вокруг условия. Переменные имеют область видимости внутри блоков, что важно учитывать при разработке.
