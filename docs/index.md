# Go Fundamentals book

> 📚 Практическое руководство по языку Go — от основ к системному пониманию

## 🚀 О книге

**Go Fundamentals book** — это структурированное руководство по языку Go, ориентированное на глубокое понимание того, как язык работает *под капотом*: память, типы, конкурентность, модель выполнения и практические паттерны.

Книга предназначена не только для изучения синтаксиса, но и для формирования **инженерного мышления при работе с Go**.

Здесь вы найдёте:

- чёткие объяснения фундаментальных концепций Go
- примеры, приближённые к реальным задачам
- разборы работы памяти, типов и рантайма
- материалы по конкурентности и устройству горутин
- практические рекомендации по проектированию кода

## 🎯 Для кого эта книга

Книга будет особенно полезна:

- разработчикам, начинающим изучать Go
- backend-разработчикам, переходящим на Go
- тем, кто хочет понимать *почему* Go работает именно так
- инженерам, которым важно системное понимание языка

## 🧭 Как изучать материал

Материал организован последовательно — от базовых типов и переменных к более сложным темам

Рекомендуется изучать главы по порядку, так как многие темы опираются на предыдущие.
